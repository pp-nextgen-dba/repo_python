# repo_python

A beginner Python project connected to GitHub.

## Setup

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Run the app:

```bash
PYTHONPATH=src python -m repo_python
```

Run tests:

```bash
PYTHONPATH=src python -m unittest discover -s tests
```
